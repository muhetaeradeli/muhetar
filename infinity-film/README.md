# Шексіздік пен мәңгілік — видео (6 минут)

Мәтін: «Қазақтың дәстүрлі қолөнеріндегі шексіздік пен мәңгілік идеясы».
Дикторлық мәтін — **мәтіннің өз сөйлемдері**: 37 сөйлем, сөзбе-сөз, мәтіндегі ретімен (`script.js` ішінде әр жолдың
жанында оның мәтіндегі нөмірі тұр); тараулардың атаулары — мәтіннің өз тақырыптары. Құжат: `doc/Дикторлық-мәтін.docx` (.pdf).

## Құрылымы (6:00)

| Тарау | Жолдар | Көрініс |
|---|---|---|
| Кіріспе | o1–o3 | Күн батқан дала, атау; жұлдызды аспан («әлемнің құрылысы · уақыттың қозғалысы · өмір мен өлім»); кеңістік · уақыт · табиғат · ұрпақ · ата-баба · адам — әрқайсысына өз суреті; қошқар мүйіз киіз |
| I. Шексіздік ұғымының мәні | d1–d5 | **Қазақтың даласы**: жылқылар; Алтын дала («ұлан-ғайыр дала · ашық аспан · алыс көкжиек · үздіксіз қозғалыс»); салт атты; ақбөкендер мен шексіз көкжиек; көш, су, тіршілік |
| II. Мәңгілік ұғымының мәні | m1–m3 | Тау шыңы («тоқтамау · жоғалмау»); отбасы; қария, әже мен немере, шебер; жеті ата тізбегі |
| III. Уақыттың циклдік сипаты | a1–a4 | Түзу сызық шеңберге айналады; таң · күн · кеш · түн; көктем · жаз · күз · қыс шеңбері; «өткен · қазіргі · болашақ» |
| IV. Кеңістік туралы түсінік | y1–y4 | Киіз үйлер; шаңырақ; уықтар; кереге шеңбері — тұйық пішін |
| V. Ою-өрнектегі шексіздік идеясы | r1–r10 | Мүйіз тәрізді пішіндер; шиыршық; ирек; тұскиіздер; қайталанатын ырғақ, тұйық жиек; «бітпес», «шимай», «шет ою»; шеңбер; «төртқұлақ» |
| VI. Уақыт пен кеңістік | k1, k3, k4 | Күн мен Ай (Ай фазалары); Темірқазық, Жетіқарақшы, Үркер; киіз үйдің жоспары: төр, босаға |
| VII. Этнодизайнға бейімдеу | n2–n5 | Ұлттық музей; ықшамдау; параметрлік өрнек (модуль, қайталану, аралық, бұрыш); музей жапсырмасы |
| VIII. Символдың шығу тегі | e2–e3 | Күн мен түн · жыл · көш · ұрпақ; шеңбер · шиыршық · ирек · тұйық · өрнек; кешкі дала, авторлар |

Кадрлар арасы — 0,6–1,2 с, тараулар арасы — 1,4 с баяу ауысу (dissolve); камера ауысу кезінде де тоқтамайды.
Түс сүзгісі (`tools/grade.filter`): жұмсақ кино қисығы, салқын көлеңке, жылы жарық, жарықтағы жұмсақ жарқыл.

## Дыбыс: дауыс 60 % / музыка 40 %

`node song.js` дауыс пен музыканы бөлек өлшейді (LUFS): музыка дауыстан 3,5 дБ төмен (40/60), жалпы −16 LUFS.

- `out/final/voice.wav` — тек дауыс, `out/final/bed.wav` — тек музыка, `out/final/music.wav` — екеуі бірге.
- Өз музыкаңызды қойсаңыз: `…-дауыс.mp4` нұсқасын алып, музыканы `bed.wav` деңгейінде (дауыстан ≈ 3,5 дБ төмен) қойыңыз.

## Жинау

    python3 tools/import_photos.py <фото қалтасы>   # assets/ + assets/credits.js
    python3 tools/build_voice.py                    # дикторлық дауыс (Piper, kk_KZ-issai-high → voices/)
    node song.js                                    # күй + дауыс → out/music.wav, voice.wav, bed.wav
    node engine/render.js video                     # сурет → out/video.mp4
    tools/finish.sh                                 # түс сүзгісі + дайын файлдар → out/final/
    python3 doc/make_doc.py                         # дикторлық мәтін → doc/Дикторлық-мәтін.docx
