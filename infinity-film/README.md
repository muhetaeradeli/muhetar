# Шексіздік пен мәңгілік — видео (10 минут)

Мәтін: «Қазақтың дәстүрлі қолөнеріндегі шексіздік пен мәңгілік идеясы» (`doc/source-text.docx`).
Дикторлық мәтін — **мәтіннің өз сөйлемдері**: 65 негізгі сөйлем, сөзбе-сөз, мәтіндегі ретімен; мәтіннің төрт бөлімі
де (дүниетанымдық негіздер · уақыт пен кеңістік · этнодизайнға бейімдеу · мәдени және этикалық талаптар) өз тақырыбымен.
Қай сөйлемдер оқылатыны — `cut.js`; барлық мәтін (335 жол, 48 мин) — `script.js` (`cut.js` ішінде `CUT = null` етсеңіз, видео толық мәтінмен жиналады).
Оқуға арналған құжат: `doc/Дикторлық-мәтін.docx` (.pdf) — әр сөйлемнің id-і, бөлімі және видеодағы уақыты.

Әр сөйлемге өз суреті немесе сызбасы бар, ал сөйлем ішіндегі сөздерге (мысалы «Ұлан-ғайыр дала», «Шаңырақ», «Темірқазық»)
сурет сол сөз айтылған сәтте ауысады (`film-plan.js`). Уақыт дауыстан өлшенеді, сондықтан басқа дауыс қойылса да сурет сөзге дәл келеді.

## Сыныптасыңыздың дауысымен

1. `doc/Дикторлық-мәтін.pdf` бойынша оқып жазыңыз. Үш тәсіл бар (араластыруға болады):
   `my-voice/all.m4a` — бүкіл мәтін бір файлда; `my-voice/c02.m4a` — бір бөлім; `my-voice/L011.m4a` — бір сөйлем.
   Әр сөйлемнен кейін ≈ 1 с кідіріс жасаңыз: `tools/build_voice.py` жазбаны сол кідірістерден сөйлемдерге бөледі
   (`out/vo-split-report.txt` — әр кесіндінің есебі, күмәнді жерлер «<- check» белгісімен).
2. Қайта жинау:

        python3 tools/build_voice.py      # жазбалар → out/vo/ + voice-timing.js (бүкіл видеоның уақыты)
        node song.js                      # күй жаңа уақытқа қайта жазылады; дауыс 60 % / музыка 40 %
        tools/render_all.sh               # сурет, 2560×1440 (RES=1080 — 1920×1080)
        tools/finish.sh                   # түс сүзгісі + дайын файлдар → out/final/
        python3 doc/make_doc.py           # құжаттағы уақыттар да жаңарады

Видеоның ұзақтығы оқушының қарқынына қарай сәл өзгереді — бұл қалыпты.
Жазбаны тікелей видеоның үстіне оқығыңыз келсе, `…-дауыссыз.mp4` (тек музыка, субтитрмен) нұсқасы бар.

## Дыбыс: дауыс 60 % / музыка 40 %

`node song.js` дауыс пен музыканы бөлек өлшейді (LUFS): музыка дауыстан 3,5 дБ төмен (40/60), жалпы −16 LUFS.
`out/final/voice.wav` — тек дауыс, `bed.wav` — тек музыка, `music.wav` — екеуі бірге.
