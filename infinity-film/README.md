# Шексіздік пен мәңгілік — видео (6 минут)

Мәтін: «Қазақтың дәстүрлі қолөнеріндегі шексіздік пен мәңгілік идеясы».
Дикторлық мәтін — бір тұтас, ауызша оқуға ыңғайлы мақала: `doc/Дикторлық-мәтін.docx` (.pdf).

## Құрылымы (6:00)

| Тарау | Жолдар | Көрініс |
|---|---|---|
| Кіріспе | o1–o5 | Күн батқан дала, атау; жұлдызды аспан мен үш сұрақ; шебер әйел; қошқар мүйіз киіз |
| I. Қазақтың даласы | d1–d8 | Жылқылар, Алтын дала («Ұлан-ғайыр дала · ашық аспан · алыс көкжиек»), салт атты, ақбөкендер мен шексіз көкжиек, бүркітшілер, өзен, гүлдеген өрік |
| II. Аспан мен уақыт | a1–a9 | Ай фазалары; Жетіқарақшы → Темірқазық, Үркер; түзу сызық шеңберге айналады; таң–күн–кеш–түн; төрт мезгіл шеңбері; мүшел; «соңы — басы» |
| III. Мәңгілік | m1–m7 | Тау шыңы; қария; әже мен немере; жеті ата тізбегі; жүн иірген шебер; тұскиіз ұстаған отбасы; «өткен · бүгін · болашақ» |
| IV. Киіз үй | y1–y7 | Киіз үйлер; кереге шеңбері; үйдің іші; уықтар; шаңырақ; үстінен қарағандағы жоспар (төр, ошақ, босаға) |
| V. Ою-өрнек | r1–r12 | Киіз бен тұскиіз; қайталанатын ырғақ; шеңбер; шиыршық; ирек; мүйіз тәрізді пішіндер; «бітпес», «шет ою»; «төртқұлақ»; музей, ер-тұрман |
| VI. Бүгінгі этнодизайн | n1–n8 | Хан Шатыр; киім · интерьер · графика · цифрлық орта; Ұлттық музей; ықшамдау; параметрлік өрнек; музей жапсырмасы |
| Қорытынды | e1–e4 | Шексіздік / мәңгілік; шаңырақ; ою; кешкі дала; авторлар |

Кадрлар арасы — 1,2 с, тараулар арасы — 1,4 с баяу ауысу (dissolve); камера ауысу кезінде де тоқтамайды.
Түс сүзгісі (`tools/grade.filter`): жұмсақ кино қисығы, салқын көлеңке, жылы жарық, жарықтағы жұмсақ жарқыл.

## Дыбыс: дауыс 60 % / музыка 40 %

`node song.js` дауыс пен музыканы бөлек өлшейді (LUFS): музыка дауыстан 3,5 дБ төмен (40/60), жалпы −16 LUFS.

- `out/final/voice.wav` — тек дауыс, `out/final/bed.wav` — тек музыка, `out/final/music.wav` — екеуі бірге.
- Өз музыкаңызды қойсаңыз: `…-дауыс.mp4` нұсқасын алып, музыканы `bed.wav` деңгейінде (дауыстан ≈ 3,5 дБ төмен) қойыңыз.

## Жинау

    python3 tools/import_photos.py <фото қалтасы>   # assets/ + assets/credits.js
    python3 tools/build_voice.py                    # дикторлық дауыс (Piper, kk_KZ-issai-high → voices/)
    node song.js                                    # күй + дауыс → out/music.wav, voice.wav, bed.wav
    node engine/render.js video                     # сурет → out/video.mp4
    tools/finish.sh                                 # түс сүзгісі + дайын файлдар → out/final/
    python3 doc/make_doc.py                         # дикторлық мәтін → doc/Дикторлық-мәтін.docx
