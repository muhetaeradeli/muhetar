# Шексіздік пен мәңгілік — видео (1 минуттық нобай)

Мәтін: «Қазақтың дәстүрлі қолөнеріндегі шексіздік пен мәңгілік идеясы» (2.1-бөлім).
Тапсырыс: мәтінге видео; «Қазақтың даласы» туралы айтылған жерде дала суреттерін көрсету.

## Құрылымы (≈73 с)

| Сахна | Дикторлық мәтін | Көрініс |
|---|---|---|
| open | o1 | Күн батқан дала (фото), атау |
| steppe | d1–d3 | **Қазақтың даласы** (фото): жылқылар, Алтын дала, ақбөкендер мен көкжиек — шексіздік сызығы |
| sky | a1 | Күн батуы → жұлдызды аспан (фото); жыл мезгілдерінің шеңбері |
| yurt | y1–y2 | Киіз үй, ішіне кіріп уықтар мен шаңыраққа қарай көтерілу (фото) |
| ornament | r1 | Тұскиіз бен сырмақ (фото) → үзілмейтін ою (қошқар мүйіз, ирек) |
| end | e1 | Кешкі дала (фото), атау, авторлар |

Сахналар арасы — 1,4 с баяу ауысу (dissolve), сахна ішінде — 1,2 с; камера ауысу кезінде де қозғалады.

## Жинау

    python3 tools/import_photos.py <фото қалтасы>   # assets/ + assets/credits.js
    python3 tools/build_voice.py                    # дикторлық дауыс (Piper, kk_KZ-issai-high → voices/)
    node song.js                                    # домбыра күйі + дауыс → out/music.wav
    node engine/render.js video && node engine/render.js mux infinity
