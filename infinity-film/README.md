# Шексіздік пен мәңгілік — видео (1 минуттық нобай)

Мәтін: «Қазақтың дәстүрлі қолөнеріндегі шексіздік пен мәңгілік идеясы» (2.1-бөлім).
Тапсырыс: мәтінге видео; «Қазақтың даласы» туралы айтылған жерде дала суреттерін көрсету.

## Құрылымы (≈73 с)

| Сахна | Дикторлық мәтін | Көрініс |
|---|---|---|
| open | o1 | Күн батқан дала, атау |
| steppe | d1–d3 | **Қазақтың даласы**: жылқылар, панорама, көкжиек — шексіздік сызығы |
| sky | a1 | Күн батып, Ай шығады; жыл мезгілдерінің шеңбері |
| yurt | y1–y2 | Киіз үй, шаңырақ (баяу айналады) |
| ornament | r1 | Сырмақ, үзілмейтін ою (қошқар мүйіз, ирек) |
| end | e1 | Дала, атау, авторлар |

## Жинау

    python3 tools/import_photos.py <фото қалтасы>   # assets/ + assets/credits.js (Wikimedia Commons)
    python3 tools/build_voice.py                    # дикторлық дауыс (Piper, kk_KZ-issai-high → voices/)
    node song.js                                    # домбыра күйі + дауыс → out/music.wav
    node engine/render.js video && node engine/render.js mux infinity

Фото жоқ болса, сол кадр салынған (анимациялық) далаға ауысады.
Өз дауысыңызбен: әр жолды `my-voice/<id>.m4a` етіп жазып қойыңыз (id — script.js ішінде).
Өз күйіңіз: `my-music/` қалтасына бір аудио файл.
