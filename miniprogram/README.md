# 快来拼豆吧（微信小程序版）

## 在电脑上预览

1. 下载并安装「微信开发者工具」：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 打开工具，用微信扫码登录 →「导入项目」→ 目录选这个 `miniprogram` 文件夹。
3. AppID：还没注册时选「测试号」即可先看效果；注册好后填你自己的 AppID（也可以改 `project.config.json` 里的 `appid`）。
4. 点「预览」会出一个二维码，用手机微信扫一下就能在手机上玩。

## 上线让所有人都能玩

1. 到 https://mp.weixin.qq.com 注册小程序（个人主体即可），名称填「快来拼豆吧」。
2. 类目建议选「工具 → 图片/设计」这类创作工具。
3. 后台完成「小程序备案」。
4. 后台「设置 → 服务内容声明 → 用户隐私保护指引」里勾选「相册（仅写入）权限」，用途写「保存用户的拼豆作品图片」，否则“存到相册”会被拦截。
5. 开发者工具里点「上传」→ 后台「版本管理」提交审核 → 通过后点「发布」。

## 文件说明

- `pages/index/index.js`：游戏逻辑（画板、熨烫、临摹挑战、保存相册、分享）
- `pages/index/index.wxml` / `index.wxss`：界面和样式
- `app.json`：全局配置（标题栏等）
