# 用你自己的声音配音 / Өз дауысыңызбен оқу

每一句录成一个单独的音频文件，文件名用下表的「文件名」（支持 .wav / .mp3 / .m4a），放进这个 my-voice/ 文件夹，然后发给 Claude 或运行：

    python3 tools/build_voice.py && node song.js && node engine/render.js video && node engine/render.js mux

影片会按你的录音长度自动重新对齐画面、字幕和音乐。没有录的句子继续用合成旁白。

也可以把全部台词一口气录成一个文件发过来（句与句之间停顿约 1 秒），由 Claude 来切分。
